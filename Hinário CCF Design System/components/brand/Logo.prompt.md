One-sentence: The Comunidade Cristã em Fortaleza brand lockup, rendered from the real exported bitmaps — use for splash screens, headers, and any brand placement.

```jsx
<Logo variant="full" height={56} />
<Logo variant="mark" height={40} />
```

Variants: `full` (house mark + wordmark) and `mark` (house mark only). Never recreate the mark as SVG; this component always references the source PNG. For the in-app "Hinário" header lockup, use `AppHeader` instead.
